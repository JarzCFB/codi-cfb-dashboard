# V4 situational research

V4 is a separate research-only review of upcoming games. It does not modify locked V3 margins, official picks, or existing grading.

Optional `v4/evidence.csv` columns: `game_id,team,player,position,factor,status,source,observed_at_utc,notes,impact_points`.

Supported factors: quarterback, star_player, injury, stadium, travel, rest, weather, rivalry, big_game. Use verified, timestamped sources; include an individual row for each outstanding player or situational finding. Missing evidence is shown as **not verified**, never as confirmation of health or absence of a situational factor. No automatic injury/player feed or calibrated points adjustment is connected yet. `impact_points` is reserved for future research and is not applied. Validate sourced adjustments with walk-forward testing before using for decisions.
